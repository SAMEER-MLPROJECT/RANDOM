# QUANTARA presentation package

**Understand the mathematics behind every trade.** Follow one fictional supplier disruption through its source records, a matched statistical test, a position-size decision and the eventual paper-trade receipt.

[Download all eight files](https://raw.githubusercontent.com/SAMEER-MLPROJECT/RANDOM/main/presentation/QUANTARA-presentation-package.zip)

| File | Use |
| --- | --- |
| [Editable PowerPoint](QUANTARA.pptx) | 17 widescreen slides with editable diagrams, tables, a chart and embedded presenter notes |
| [PDF slides](QUANTARA.pdf) | View or share the rendered 17-page deck |
| [Speaker script](Speaker-script.docx) | 6 min 04 s, with visual cues and technical detail for questions |
| [Guided demo](Demo-script.docx) | 3 min 35 s, from the initial event to the closed ten-share VYRA trade |
| [Source register](Source-register.docx) | Linked prototype evidence, publications, image credits and previous research |
| [Claim-verification matrix](Claim-verification.xlsx) | Filter claims by slide or type of evidence |
| [Implementation-status matrix](Implementation-status.xlsx) | Inspect each feature, verification method and remaining limitations |
| [Competition-compliance checklist](Compliance-checklist.docx) | Project and workshop requirements, plus outstanding organizer checks |

The deck was checked against [prototype revision d6f90c4](https://github.com/SAMEER-MLPROJECT/RANDOM/tree/d6f90c4c7c7e8d92db5445a434391c3f377155b3). The demo uses the default fictional sources and a fresh browser profile. Launch locally with Node.js 24 and `npm start`, then open `http://127.0.0.1:8000`. The [workshop walkthrough](../docs/DEMONSTRATION.md) gives a separate two-minute version.

The nine-window case yielded an inconclusive verdict. In the broader [held-out synthetic benchmark](../docs/BENCHMARK.md), none of the five prespecified paired comparisons established a return advantage. The organizer’s official rulebook and submission requirements were unavailable.
